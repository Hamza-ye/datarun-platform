# Operational Policies

Status: active operational-policy index

Policies record deployment-owner decisions such as service ownership, RPO/RTO,
backup retention, secrets rotation, release approval, incident severity,
support escalation, and evidence retention.

Policies state what is chosen and who owns it. They do not contain long command
sequences, claim runtime capability, or modify architecture and contracts.

## Required Shape

- required metadata from
  [documentation-organization.md](../../documentation-organization.md);
- policy scope and owner;
- decision and rationale;
- mandatory controls and allowed exceptions;
- review cadence or trigger;
- escalation and approval path;
- affected runbooks, specifications, and successor work.
